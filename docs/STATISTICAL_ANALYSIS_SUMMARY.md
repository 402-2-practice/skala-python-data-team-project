## 1. 담당 TASK

연구 질문은 다음과 같다.

> 관측된 배경 특성을 조정한 뒤에도 대학 학위 보유와 고소득(연 5만 달러 초과) 여부의 연관성이 남아 있는가?

통계 담당의 구체적인 책임은 다음과 같다.

1. 학위·비학위 집단의 고소득률을 기술통계로 비교한다.
2. 과제 요구사항인 `scipy.stats.ttest_ind`를 이용해 Welch t-test를 수행한다.
3. p-value뿐 아니라 비율 차이, 95% 신뢰구간, 위험비, 오즈비, Cohen's h를 함께 제시한다.
4. 교육 이전 특성을 사용한 주 성향점수매칭(PSM)을 수행한다.
5. 직업·근무시간까지 포함한 민감도 PSM을 별도로 수행한다.
6. 매칭 전후 표준화 평균차이(SMD)를 이용해 실제 균형 개선 여부를 확인한다.
7. 매칭 표본 수, 탈락률, 매칭 거리, 대조군 중복 사용 여부를 기록한다.
8. 결과를 JSON·CSV로 저장해 시각화와 `report.md`가 재사용할 수 있게 한다.
9. 관찰 데이터의 한계와 ML 변수 중요도의 의미를 구분해 설명한다.

## 2. 분석 설계

### 처리와 결과

- 처리: `college_degree` — 대학 학위 보유 1, 미보유 0
- 결과: `high_income` — 연 소득 5만 달러 초과 1, 이하 0

### 매칭 전 비교

0/1 결과의 평균은 고소득자 비율과 같다. 과제 요구에 따라 Welch t-test를 사용하되, 표본이 크기 때문에 p-value만 강조하지 않고 비율 차이와 효과크기를 함께 보고한다.

### 주 PSM

공변량:

- `age`
- `sex`
- `race`
- `native-country`

직업과 근무시간은 교육 이후 달라질 수 있는 매개변수이므로 주 PSM에서는 제외한다. 주 PSM은 직업을 통한 경로까지 포함한 학위의 전체적인 연관성을 보려는 분석이다.

### 민감도 PSM

주 PSM 공변량에 다음을 추가한다.

- `occupation`
- `hours-per-week`

이 결과는 현재 직업과 근무시간까지 비슷한 사람 사이에서 남는 학위의 조건부 연관성이다. 교육의 총효과라고 해석하지 않는다.

### 매칭 방법

- 로지스틱 회귀로 학위 보유 성향점수 계산
- 성향점수의 logit 척도에서 공통지지 영역 적용
- logit 성향점수 표준편차의 0.2를 caliper로 사용
- 1:1 greedy nearest-neighbor matching
- 대조군 중복 사용 금지
- 절대 SMD 0.1 미만을 균형 기준으로 사용

기존 코드는 대조군 재사용을 허용해 주 분석 7,580쌍 중 고유 대조군이 657명뿐이었고, 한 명이 최대 168번 사용됐다. 반복된 표본을 독립 표본처럼 검정하는 문제를 줄이기 위해 기본값을 중복 없는 매칭으로 변경했다.

## 3. 실제 데이터 결과

현재 데이터 파이프라인의 정제 결과 30,139행을 사용했다.

### 매칭 전

| 지표 | 결과 |
|---|---:|
| 비학위 집단 | 22,554명 |
| 학위 집단 | 7,585명 |
| 비학위 집단 고소득률 | 16.74% |
| 학위 집단 고소득률 | 49.18% |
| 단순 차이 | 32.43%p |
| 차이의 95% CI | 31.21%p ~ 33.66%p |
| 위험비 | 2.94 |
| 오즈비 | 4.81 |
| Cohen's h | 0.71 |
| Welch t-test p-value | < 1e-300 |

두 집단의 고소득률 차이는 통계적으로 유의하지만, 집단의 배경 특성이 다르므로 이 결과만으로 학위의 인과효과를 주장할 수 없다.

### 주 PSM

| 지표 | 결과 |
|---|---:|
| 매칭 쌍 | 7,479쌍 |
| 학위 집단 유지율 | 98.60% |
| 고유 대조군 | 7,479명 |
| 대조군 재사용 | 0% |
| 비학위 집단 고소득률 | 21.62% |
| 학위 집단 고소득률 | 49.06% |
| 매칭 후 차이 | 27.44%p |
| 최대 SMD | 0.224 → 0.046 |
| SMD 0.1 이상 공변량 | 6개 → 0개 |
| p-value | 4.49e-281 |

관측된 교육 이전 특성을 조정한 뒤에도 27.44%p의 차이가 남았다. 그러나 능력, 가정환경, 지역, 교육비처럼 데이터에 없는 교란요인은 통제되지 않았다.

### 직업·근무시간 포함 민감도 PSM

| 지표 | 결과 |
|---|---:|
| 매칭 쌍 | 5,423쌍 |
| 학위 집단 유지율 | 71.50% |
| 비학위 집단 고소득률 | 28.21% |
| 학위 집단 고소득률 | 46.23% |
| 조건부 차이 | 18.02%p |
| 최대 SMD | 0.941 → 0.082 |
| SMD 0.1 이상 공변량 | 16개 → 0개 |
| p-value | 2.54e-85 |

직업·근무시간까지 비슷하게 만들면 차이가 27.44%p에서 18.02%p로 감소한다. 이는 직업과 근무시간이 학위와 고소득을 연결하는 경로일 가능성을 보여주지만, 별도의 매개효과 분석 없이 그 경로를 확정할 수는 없다.

## 4. ML 결과와 PSM 결과의 관계

ML 담당 결과에서 `college_degree` 또는 `education`의 permutation importance가 13개 피처 중 6~8위이고 `marital-status`가 1위였다는 사실은 PSM 결과와 모순되지 않는다.

- permutation importance: 이미 주어진 여러 변수를 함께 사용할 때 예측 성능에 얼마나 기여했는가?
- PSM: 관측 배경이 비슷한 사람을 비교했을 때 학위 집단의 결과 차이가 얼마나 남는가?

예측 기여도는 인과효과 순위가 아니다. 특히 직업, 혼인상태, 자본이득처럼 소득과 가까운 변수가 포함되면 교육 정보가 일부 중복되어 학력의 예측 순위가 낮아질 수 있다.
