# 분석 설계와 의미

## 1. 처리와 결과

- 처리(treatment): 대학 학위 보유 여부 `college_degree`
- 결과(outcome): 연 소득 5만 달러 초과 여부 `high_income`
- 분석 단위: Adult Census 데이터의 개인 레코드

이 데이터에는 실제 소득액이 없다. 따라서 "대학 학위의 금전적 수익률"을 계산하는 프로젝트가 아니라 "대학 학위 보유와 5만 달러 기준 초과 확률의 관계"를 분석하는 프로젝트다.

## 2. 분석을 세 층으로 분리하는 이유

### 단순 비교

학위 집단과 비학위 집단의 고소득률 차이를 계산한다. 실제 데이터의 격차를 보여주지만 집단의 나이·성별·출신 국가 등이 다르므로 인과효과로 해석하지 않는다.

### 성향점수매칭

관측된 배경 특성을 이용해 대학 학위 취득 가능성이 유사한 사람을 비교한다. 단순 비교보다 조건이 비슷한 집단을 만들지만, 데이터에 없는 가정환경·개인 능력·지역·교육비 등은 통제하지 못한다.

PSM 공변량은 우선 다음으로 제한한다.

- age
- sex
- race
- native-country

`occupation`, `workclass`, `hours-per-week`, `capital-gain`은 교육 이후에 형성될 수 있다. 대학 교육이 직업을 바꾸고 직업이 소득에 영향을 주는 경로까지 통제하면 교육의 총효과 일부를 제거할 수 있으므로 기본 PSM에서 제외한다.

인과 구조를 단순화하면 다음과 같다.

```text
교육 이전 배경 ─→ 대학 학위 ─→ 직업·근무시간 ─→ 고소득 여부
       └──────────────────────────────→ 고소득 여부
```

여기서 직업과 근무시간을 동일하게 맞추면 `대학 학위 → 직업·근무시간 → 소득` 경로가 막힌다. 그러므로 이것은 "다른 조건이 같을 때 학위의 순수한 총효과"가 아니라, 직업과 근무 형태를 고정했을 때 남는 직접적 연관성에 가까운 분석이다.

## 3. 팀원 제안의 반영 방법

팀원이 제안한 "매칭으로 가짜 실험 만들기"는 직관적인 설명으로 활용하되 다음처럼 정확히 표현한다.

- `클러스터링`과 `성향점수매칭`은 같은 방법이 아니므로 보고서에서는 PSM이라는 정확한 명칭을 쓴다.
- PSM은 무작위 실험을 재현하거나 모든 조건을 같게 만드는 방법이 아니다.
- 처리집단과 비교집단이 관측된 공변량에서 비슷해지도록 만드는 준실험적 접근이다.
- 주 분석은 교육 이전 배경변수로 학위 취득 가능성을 계산한다.
- 직업·근무시간 포함 결과는 주 분석이 아니라 민감도 분석으로 제시한다.
- 매칭 후 차이가 남더라도 "학력이 원인으로 증명됐다"가 아니라 "관측된 배경을 조정한 뒤에도 연관성이 남았다"고 쓴다.

### 두 분석이 답하는 질문

| 분석 | 통제 변수 | 답하려는 질문 |
|---|---|---|
| 주 PSM | age, sex, race, native-country | 대학 학위가 직업 변화 등을 포함해 고소득과 연결되는 전체 경로가 남는가? |
| 민감도 분석 | 주 PSM 변수 + occupation + hours-per-week | 현재 직업과 근무시간까지 같을 때 학위와 고소득의 직접적 연관성이 남는가? |

두 결과의 차이가 크면 직업과 근무시간이 대학 학위와 고소득을 연결하는 중요한 경로일 가능성을 제시할 수 있다. 그러나 이 차이만으로 매개효과를 확정할 수는 없다.

### 예측 모델

전처리와 Logistic Regression을 sklearn Pipeline으로 묶어 고소득 여부를 예측한다. 예측 모델은 과제의 ML 요구사항과 변수 조합의 예측력을 확인하기 위한 보조 분석이다.

높은 예측 정확도는 인과관계의 증거가 아니다. "미래 결과를 잘 맞힌다"와 "학위 때문에 결과가 변했다"는 서로 다른 질문이다.

## 4. 필수 해석 원칙

- p-value가 작다는 것은 효과가 크다는 의미가 아니다. 고소득률 차이를 함께 보고한다.
- PSM 전후의 차이를 모두 보고한다.
- 매칭된 표본 수와 공통지지 영역을 보고한다.
- 전체 Accuracy만 보고하지 않고 Precision, Recall, F1, ROC-AUC를 함께 보고한다.
- 분석 시점과 지역적 배경이 다른 현재 한국의 개인에게 결과를 그대로 일반화하지 않는다.
- 성별·인종별 격차를 개인 능력 차이로 해석하지 않는다.

## 5. 현재 뼈대 이후 개선 항목

- PSM 전후 표준화 평균차이(SMD)와 Love plot 추가
- 최근접 이웃 중복 사용 민감도 분석
- 학사 대 고졸로 표본을 제한한 강건성 분석
- `fnlwgt`를 표본 가중치로 적용한 기술통계 비교
- Logistic Regression과 Random Forest 성능 비교
- 민감변수 집단별 Recall 및 False Negative Rate 비교
